Root replaced this with an explicit reviewed rollback SHA from dispatch input or repository configuration; missing or same-candidate targets must fail. A distinct compatible target still needs actual verification, or a separately reviewed forward-recovery-only strategy.
3. **Resolved, documentation drift:** README now lists refund created/updated/failed and dispute updated/closed events alongside existing events and replaces stale mandatory-malware-scanning wording with approved structural file-safety/isolation. The rehearsal runbook explicitly requires an administrator and says the operator role alone is insufficient. These wording corrections do not grant provider mutation permission.
4. **Resolved, unsafe hosted replay wording:** README now limits complete migration replay to a disposable local database and requires observed hosted ledger, exact approval, quiescence, encrypted backup and isolated restore evidence before a bound forward runner. It also documents the absence of a proven schema-085 rollback candidate and distinguishes isolated image checks from hosted AWS proof.

Root added the exact type check and rejects the presence of any resource `Condition`; existing exact unconditional statement checks still require a denial for every principal. The reviewer independently read that four-line fix. The initial focused receipt preserves 179/180 passing tests and this one failure. `aws-cleanup-negative-replay-results.json` records the corrected template and maintenance suites passing 24/24 tests with zero skipped/pending tests; the required-results validator also passed. `aws-cleanup-targeted-reviewed.json` binds the tested source and receipt hashes and makes the focused/external evidence boundary explicit.

Summary now requires safe nonnegative integer counts for pending, dead-letter and due AWS queries before reporting database or maintenance readiness. Missing counts no longer become healthy zeroes. The reviewer independently read these root-authored guards; the reviewer's own cleanup processor and maintenance diagnostic additions remain excluded from independent review.
